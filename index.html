🚀 Guia Passo a Passo: VS Code + Firebase + GitHub

Feito sob medida para você colocar o sistema no ar mesmo sem ser programador

Passo 1: Rodar agora mesmo no seu VS Code

  1. Baixe o arquivo deste sistema (ou crie uma pasta sgo-uffs-realeza no seu computador e abra no VS Code).
  2. Salve o arquivo principal como index.html (quando hospeda no Firebase ou GitHub Pages, o arquivo principal deve se chamar index.html).
  3. No VS Code, clique com o botão direito no index.html e escolha "Open with Live Server" (ou dê dois cliques no arquivo para abrir no Chrome).
  4. Use o botão abaixo para baixar o arquivo database_uffs_2026.json caso queira importar a coleção inicial direto no Firestore.

Passo 2: Configurar o Login e Banco no Firebase (Console Web)

  1. Acesse console.firebase.google.com e crie um projeto (ex: orcamento-uffs-realeza) ou use o que você já tem.
  2. No menu lateral, clique em Authentication → Vamos começar → ative a opção E-mail/senha. Lá você cadastra os e-mails dos coordenadores (ex: coord.bio.re@uffs.edu.br).
  3. No menu lateral, clique em Firestore Database → Criar banco de dados → inicie no Modo de Teste (ou Produção).
  4. Vá na engrenagem (Configurações do Projeto) → role até o fim em Seus aplicativos → clique no ícone Web </> e copie o bloco firebaseConfig.

Passo 3: Subir para o GitHub e Publicar Grátis

  1. No VS Code, clique no ícone de Controle de Código-Fonte (3º ícone na barra esquerda) → Publish to GitHub.
  2. Para deixar o site acessível por link para os coordenadores da UFFS, você pode ativar o GitHub Pages (Settings → Pages → Branch main) ou usar o Firebase Hosting.
